The Dottie Analytics API is a first-party telemetry and web-analytics service (an Umami replacement) at this server's origin (the host serving this page). It ingests desktop app pings and product events, serves the admin reports behind the dashboard, hosts multi-tenant website analytics, and tracks GitHub growth.

The service is deliberately invisible to the public web: the root / returns 404, bots are disallowed, and every response carries X-Robots-Tag: noindex, nofollow, noarchive. Report and admin endpoints require Authorization: Bearer <DOTTIE_ADMIN_KEY>; a missing or wrong key returns 404 (not 401/403) so endpoints look nonexistent to probes.

Public ingest is separate: POST /api/send (web analytics) is keyed by each site's write_key in the body, and desktop writes use the per-user bearer from /api/register. REST bodies cap at 4 KiB. For a machine-readable index, see llms.txt.
